# PassCopy 使い方説明書

PassCopy は、登録した **ID とパスワードをワンクリックでコピーできる** Windows 用の無料ツールです。
「Windows セキュリティ」の資格情報画面（ネットワークドライブやリモートデスクトップに接続するときに出る画面）など、ID とパスワードを何度も入力する場面で、一覧からコピーして貼り付けるだけで入力できます。

- 登録できるのは **最大 50 件** です。
- **完全オフライン** で動きます。インターネットには一切接続しません。
- 登録した情報は **暗号化して** この PC に保存します。

## 1. はじめに

### 起動とタスクトレイ

- 起動すると一覧画面が開き、画面右下のタスクトレイにアイコンが表示されます。
- 一覧画面を閉じてもアプリは終了しません。もう一度開くときは、タスクトレイのアイコンをクリックするか、ショートカット（初期設定は **Ctrl + Alt + P**）を押します。
- 終了するときは、タスクトレイのアイコンを右クリックして「終了」を選びます。

### 初回起動時の警告

「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押してください（コード署名をしていないために表示されます）。

## 2. 登録する

1. 一覧画面の「＋ 追加」を押します。
2. 次の項目を入力して「保存」を押します。

| 項目 | 内容 |
|---|---|
| 表示名（必須） | 一覧に表示する名前です。例: 社内ファイルサーバー |
| グループ | 仕事・自宅などの分類です。一覧に札として表示され、絞り込みにも使えます |
| ID（ユーザー名） | コピーする ID です。例: `CORP\yamada` |
| パスワード | コピーするパスワードです。👁 で表示・非表示を切り替え、🎲 でランダムなパスワード（16 文字）を作れます |
| メモ | 接続先や用途など、自由なメモです |

- 一覧の上に「5 / 50 件」のように登録数が表示されます。**50 件に達すると「＋ 追加」は押せなくなります。** 不要なものを削除してから追加してください。
- 各登録の右上のボタンで、並べ替え（▲▼）・編集（✎）・削除（🗑）ができます。削除は元に戻せません。

## 3. コピーして使う

1. 一覧画面を開きます（タスクトレイのアイコン、または Ctrl + Alt + P）。
2. 使いたい登録の「ID」または「パスワード」の欄をクリックします。欄が緑色になり、コピーされます。
3. 入力したい画面の欄をクリックし、**Ctrl + V** で貼り付けます。

> 例: 「Windows セキュリティ」の画面が出たら、PassCopy で ID をクリック → ユーザー名の欄に Ctrl + V → PassCopy でパスワードをクリック → パスワードの欄に Ctrl + V → OK。

### コピーしたパスワードは自動で消えます

- コピーしたパスワードは、初期設定では **30 秒後にクリップボードから消えます**（設定で秒数を変えられます。0 にすると消しません）。
- 消すのは、クリップボードの中身がそのパスワードのままのときだけです。その後に別の文字をコピーしていた場合は、そのままにします。
- PassCopy を終了したときも、クリップボードにパスワードが残っていれば消します。
- ID は消しません。

### 絞り込み

一覧の上の入力欄に文字を入れると、表示名・ID・グループ・メモに含まれるものだけを表示します（絞り込み中は並べ替えできません）。

## 4. 設定

「設定」タブで変更します。変更はすぐに保存されます。

| 設定 | 内容 |
|---|---|
| 一覧を開くショートカット | 一覧画面を開く・閉じるキーです。初期設定は `Ctrl+Alt+P`。空欄にすると使いません。他のアプリが使っているキーは登録できず、赤字でお知らせします |
| コピーしたパスワードを消すまでの秒数 | 初期設定は 30 秒です。0 にすると消しません |
| コピーしたら一覧を隠す | コピーした直後に一覧画面を隠します。貼り付け先の画面がすぐ見えるようになります |
| 一覧を常に最前面に表示する | ほかの画面の上に一覧を出し続けます |
| 起動したときに一覧を開く | オフにすると、起動時はタスクトレイのアイコンだけになります |
| Windows の起動時に自動で起動する | インストール版でだけ使えます |

## 5. マスターパスワード（任意）

マスターパスワードを設定すると、起動したときやロックしたあとに、そのパスワードを入れないと一覧を見られなくなります。PC を他の人と共用しているときなどに使ってください。

- 「設定」→「マスターパスワード」→「設定する」で、4 文字以上のパスワードを 2 回入力します。
- 設定すると、画面右上に 🔒 ボタンが表示されます。押すとすぐにロックします。タスクトレイのメニューからもロックできます。
- 「操作がないときに自動でロックするまでの分数」を設定すると、コピーや編集をしない状態がその分数続いたときに自動でロックします。
- **マスターパスワードを忘れると、登録した情報は取り出せません。** 大切な情報は、バックアップ（次の章）も作っておいてください。

## 6. バックアップと PC の移行

保存データは、Windows の仕組み（DPAPI）で暗号化しているため、**この PC のこの Windows ユーザーでしか読めません**。別の PC へ移すときや、PC の入れ替えに備えるときは、バックアップを使います。

### 書き出す

1. 「設定」→「バックアップ」→「書き出す…」を押します。
2. バックアップ用のパスワード（4 文字以上）を 2 回入力し、「保存先を選ぶ…」を押します。
3. 保存先を選ぶと、`PassCopy-backup-日付.pcbak` というファイルができます。

バックアップファイルはパスワードで暗号化されています。このパスワードを忘れると読み込めません。

### 読み込む

1. 移行先の PC で PassCopy を起動し、「設定」→「バックアップ」→「読み込む…」を押します。
2. 書き出したときのパスワードを入力し、読み込み方を選んで「ファイルを選ぶ…」を押します。

| 読み込み方 | 動き |
|---|---|
| 今の登録に追加する | 表示名と ID が同じものは上書きし、それ以外は追加します。合計が 50 件を超える分は取り込みません（件数をお知らせします） |
| 今の登録をすべて置き換える | 今の登録を消して、バックアップの内容にします |

## 7. 安全のためのしくみ

| しくみ | 内容 |
|---|---|
| 完全オフライン | インターネットには一切接続しません。画面は同梱のファイルだけを表示し、外部への通信はすべて遮断しています。更新の確認もしません |
| 暗号化して保存 | 保存データは Windows の DPAPI で暗号化します。マスターパスワードを設定すると、さらに AES-256-GCM で暗号化します |
| 画面にパスワードを渡さない | 一覧画面にはパスワードの「●●●●」だけを表示し、パスワードそのものはコピーや編集のときにだけ扱います |
| クリップボードの自動消去 | コピーしたパスワードは一定時間後に消えます |

### 注意

- Windows の「クリップボードの履歴」（Win + V）をオンにしていると、コピーしたパスワードが履歴に残ることがあります。気になる場合は、Windows の「設定」→「システム」→「クリップボード」で「クリップボードの履歴」をオフにしてください。
- 保存場所は `%APPDATA%\PassCopy\vault.json` です。このファイルを別の PC にコピーしても読めません（移行はバックアップを使ってください）。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| ショートカットで一覧が開かない | 他のアプリが同じキーを使っている可能性があります。「設定」で別のキー（例: `Ctrl+Alt+K`）に変えてください |
| 「＋ 追加」が押せない | 登録が 50 件に達しています。不要なものを削除してください |
| 「保存データを読み込めませんでした」と出た | Windows ユーザーが変わった、またはファイルが壊れた可能性があります。元のファイルは `vault.broken-数字.json` として残しています。バックアップがあれば読み込んでください |
| マスターパスワードを忘れた | 登録情報は取り出せません。バックアップから読み込むか、`%APPDATA%\PassCopy\vault.json` を削除して最初から登録し直してください |
